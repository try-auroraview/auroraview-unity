How the human and agent paths meet

The page calls scene.context, scene.create_cube and scene.select. The opt-in MCP adapter registers those three methods as tools. UI controls do not automatically become agent tools.

Enable Window → AuroraView → Enable Agent Endpoint in Unity, then configure agent/server.mjs --pid <EditorPID>. The endpoint stays off until explicitly enabled each session.
